# Strategist — Round 1 Position

**Recommendation:** Ship the thinnest possible MVP in 2-3 weeks. Validate adoption before investing in infrastructure.

## Key Points
- MVP: Google CSE wrapper + curated site list + basic admin panel. Nothing else.
- Phased roadmap: MVP (3wk) → V1.1 analytics (5wk) → V2 own crawler (conditional) → V3 sermon AI (conditional)
- CSE free tier (100/day) is sufficient for initial validation. Break-even for own crawler is at $30+/mo CSE spend.
- Risk #1: Zero adoption. Find 5 committed users before writing code.
- Risk #2: Building crawler too early to fix perceived quality issues
- Risk #3: Admin panel scope creep — could be a JSON file for MVP
- Success metric: 10 unique users, 100 searches in first 30 days
