# Advocate — Round 1 Position

**Recommendation:** Design for trust and simplicity. Pre-search category filtering, clean result cards with source attribution, admin table view with health monitoring.

## Key Points
- Homepage: nearly empty, centered search box, category pills below
- Pre-search filtering (not post-search) — reduces steps to relevant results
- Result cards: favicon + site name → title → snippet → URL
- "Searching 52 trusted sites" messaging reinforces the value prop
- Rename "Other" category to "General Ministry"
- Admin panel: table view (not cards), inline editing, slide-over for add, bulk operations
- Mobile: sticky search bar, horizontally scrollable category pills, 36px touch targets
- Accessibility: visible focus rings, role="radio" on category pills, 4.5:1 contrast, 16px min font
- No auto-suggest for v1 (specialized query space, latency concern)
